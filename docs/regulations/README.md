# 규정 문서 폴더

이 폴더에 사내 규정 원문(`.hwp`, `.hwpx`)을 넣고 `npm run ingest`를 실행하면 RAG 색인이 만들어집니다.

- 규정 원문은 공개 저장소에 올리지 않도록 `.gitignore`로 제외되어 있습니다.
- 파일명 규칙: `규정명(YYYY년도 M월 D일 개정).hwp` — 규정명과 개정일을 파일명에서 읽습니다.
  - 예: `인사관리규정(2026년도 3월 26일 개정).hwp`, `보수규정시행요강(2026년도 3월 10일 개정).hwp`
- 다른 폴더를 쓰려면 `.env`의 `RAG_DOCS_DIR`을 바꾸세요.
